## §7 — Accessibility

- **Contrast floors:** ≥4.5:1 normal text, ≥3:1 large text (WCAG 2.1 AA).
- **Focus visibility:** every interactive element has a visible focus ring.
- **Keyboard paths:** all flows operable without a mouse; logical tab order; no focus traps.
- **Hit targets:** ≥44×44px.
- **Motion:** `prefers-reduced-motion: reduce` respected.
- Full contrast matrix: see `docs/design/contrast.md`.

---

## §8 — Zero hardcode and paths

1. No hardcoded colors — every color reads from a token.
2. No off-scale spacing — every spacing value reads from the scale.
3. No unknown components — only manifest-listed components are imported.
4. No literal UI strings when `manifest.i18n.enabled === true` — every string reads from
   an i18n key.

**Manifest path resolution order:** explicit flag → `docs/design/manifest.json` if it
exists → legacy `design-system-manifest.json` at the project root if that is what already
exists → `docs/design/manifest.json` for new projects. If both exist, the gate fails with
a diagnostic naming both paths.

**Gate:** `node scripts/design_lint.mjs --changed` (pre-commit + CI); `/steve-designer:check`
for a full semantic + visual review.
